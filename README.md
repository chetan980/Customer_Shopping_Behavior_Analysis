# Customer Shopping Behavior Analysis

## Project Overview
An interactive Power BI dashboard designed to analyze customer shopping behavior and purchasing patterns.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Dashboard Highlights
- Total Number of Customers
- Average Purchase Amount
- Average Review Rating
- Subscription Status Analysis
- Revenue by Category
- Sales by Category
- Sales by Age Group
- Revenue by Age Group
- Customer Segmentation Filters
